## Para rodar o agente localmente

1. Clone o repositório da sua máquina (você precisará instalar o python previamente)

2. Dentro do repositório, crie um ambiente virtual. Isso pode ser feito rodando o comando abaixo no terminal:

    python -m venv .venv

3. Em seguida ative o ambiente virtual, rodando no terminal:

    .venv/Scripts/activate

4. Instale as dependências listadas no arquivo requirements.txt com o comando

    pip install -r requirements.txt

5. Inicialize a aplicação do agente com o comando 

    python .\Agent\src\app.py
